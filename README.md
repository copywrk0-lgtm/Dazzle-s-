# Dazzle PPF Demo v2

A serious sales-demo build for Dazzle Detailing Studio.

## Stack
- Next.js 15 App Router
- React + TypeScript
- Tailwind CSS
- Anime.js
- Lucide icons
- Reusable Aceternity-inspired UI patterns: spotlight, beams, glowing cards, moving borders, magnetic interaction, reveal-on-scroll
- Responsive mobile-first layout

## Run
npm install
npm run dev

## Build
npm run build

## Notes
This is a concept/demo. Business facts, pricing, testimonials, imagery, warranties, certifications and contact workflows must be verified with the client before production.

The visual system is inspired by modern premium product sites and Aceternity UI patterns. It does not copy proprietary source code or assets from third-party sites.
